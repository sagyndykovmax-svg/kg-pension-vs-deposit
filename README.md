# Соцфонд или депозит?

Сравнение двух способов копить на пенсию в Кыргызстане:

1. обязательные взносы в Социальный фонд КР и накопительная часть в ГНПФ;
2. самостоятельные накопления на сомовых банковских депозитах.

Данные собраны **05.10.2026**.

Это одна HTML-страница (`index.html`). Внутри:

- схема того, куда уходят взносы с зарплаты;
- разбор законодательства;
- доходность ГНПФ и инфляция;
- ставки депозитов и защита вкладов;
- интерактивный калькулятор сложного процента;
- риски, итоговый вывод и точка безубыточности.

## Как открыть

- **Локально:** скачайте `index.html` и откройте в браузере. Сервер не нужен, всё работает офлайн. Нужен только интернет для шрифтов Google Fonts, без него подставятся системные шрифты.
- **Через GitHub Pages:** в репозитории откройте Settings → Pages → Build and deployment → Source: *Deploy from a branch*, выберите ветку `main` и папку `/ (root)`. Через минуту страница будет доступна по адресу `https://<ваш-логин>.github.io/<имя-репозитория>/`.

## Как читать метки

| Метка | Значение |
|---|---|
| **Д** | Данные из источника. Ссылка указана рядом, с оригиналом не сверено |
| **Р** | Расчёт (формула сложного процента с ежемесячными взносами) |
| **И** | Интерпретация автора исследования |

## Ограничения

- Официальные сайты в зоне `.kg` (sf.gov.kg, nbkr.kg, deposit.kg, cbd.minjust.gov.kg, сайты банков) при сборе данных не открывались. Цифры взяты из поисковой выдачи по указанным адресам.
- Ставка, которую ГНПФ зачисляет на личные пенсионные счета, не найдена ни за один год. Сценарии доходности ГНПФ — оценка.
- Ставки банков не сверены с сайтами банков.
- Общая уверенность в выводах ≈50%. Перед решениями сверяйте ключевые цифры с первоисточниками.
